How the brand is built — and reproduced

01 · The lockup — and the spacing rule

The mark sits left of the wordmark. Spacing rule (fixes the drift): mark height = 1.28× the wordmark's letter height; gap between mark and wordmark = 0.26× the mark's height; the descriptor sits under the wordmark, left-aligned, at 0.155× the wordmark size, letterspaced. Asset files are pre-composed to this rule — use them rather than rebuilding.

Clear space: keep a margin equal to the width of the mark's window block on all four sides of any lockup. Nothing enters it — not taglines, not partner logos, not page edges.

Fraunces (SemiBold 600) for headlines and the wordmark; Public Sans for everything read at length. Rules: body 16px minimum, always. Brass carries headlines and accents only — never body text. Navy/ivory pairings pass AAA. Off-limits: care-sector teals and lavenders, hearts, clasped hands. CMYK values are converted at the print vendor from the hex above — don't eyeball them.

04 · Never
  • Redraw, retype, or approximate the mark — the vial and geometry reproduce from asset files only
  • Stretch, rotate, outline, shadow, or gradient anything
  • Recolour outside the palette; never brass body text
  • Put the region in the mark — it lives in the descriptor
  • Run the round-8 illustration set as a second logo
  • Pair the mark with hands, hearts, shields, or checkmarks
